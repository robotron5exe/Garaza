:: GENERALIZED GAUSSIAN DISTRIBUTION ::

$ Overview

The Generalized Gaussian Distribution (GGD), also known as the Exponential Power Distribution, is a parametric probability distribution that extends the standard Gaussian distribution by introducing a shape parameter that controls the tail behavior.

⚡ Use Cases: Signal processing, image analysis, financial modeling, robust statistics

$ Mathematical Definition

probability_density_function.py

The probability density function (PDF) of the GGD is given by:

$$ f(x|\mu, \alpha, \beta) = \frac{\beta}{2\alpha\Gamma(1/\beta)} \exp\left(-\left|\frac{x-\mu}{\alpha}\right|^\beta\right) $$
μ (mu) → Location parameter (mean)
α (alpha) → Scale parameter (controls spread)
β (beta) → Shape parameter (controls tail behavior)
Γ → Gamma function

$ Shape Parameter Analysis

β = 1

Laplace Distribution

Heavy tails, sharp peak

$$f(x) = \frac{1}{2\alpha}e^{-|x-\mu|/\alpha}$$
β = 2

Gaussian Distribution

Standard normal tails

$$f(x) = \frac{1}{\alpha\sqrt{2\pi}}e^{-(x-\mu)^2/(2\alpha^2)}$$
β → ∞

Uniform Distribution

Bounded support, flat top

$$f(x) = \frac{1}{2\alpha}, |x-\mu| \leq \alpha$$
0 < β < 2

Super-Gaussian

Heavier tails than normal

Used for impulsive noise

$ Implementation Example

ggd_implementation.py
import numpy as np
from scipy.special import gamma

def generalized_gaussian_pdf(x, mu, alpha, beta):
    """
    Compute the Generalized Gaussian Distribution PDF

    Parameters:
    -----------
    x : array_like
        Input values
    mu : float
        Location parameter (mean)
    alpha : float
        Scale parameter (must be > 0)
    beta : float
        Shape parameter (must be > 0)

    Returns:
    --------
    pdf : ndarray
        Probability density values
    """
    # Normalize the input
    z = np.abs((x - mu) / alpha)

    # Compute normalization constant
    norm_const = beta / (2 * alpha * gamma(1/beta))

    # Compute PDF
    pdf = norm_const * np.exp(-z**beta)

    return pdf

# Example usage
x = np.linspace(-5, 5, 1000)
mu, alpha = 0, 1

# Compare different shape parameters
beta_laplace = 1.0    # Heavy tails
beta_gaussian = 2.0   # Normal distribution
beta_super = 4.0      # Light tails

pdf_laplace = generalized_gaussian_pdf(x, mu, alpha, beta_laplace)
pdf_gaussian = generalized_gaussian_pdf(x, mu, alpha, beta_gaussian)
pdf_super = generalized_gaussian_pdf(x, mu, alpha, beta_super)

print("[✓] GGD computation completed successfully")

$ Parameter Estimation

estimation_methods.txt

1. Maximum Likelihood Estimation (MLE)

Optimize the log-likelihood function:

$$\ell(\mu,\alpha,\beta) = n\log\frac{\beta}{2\alpha\Gamma(1/\beta)} - \sum_{i=1}^n \left|\frac{x_i-\mu}{\alpha}\right|^\beta$$

Requires numerical optimization (Newton-Raphson, EM algorithm)

2. Method of Moments

Match sample moments to theoretical moments:

  • Sample mean → μ
  • Sample variance and kurtosis → α, β

Faster but less efficient than MLE

3. Robust M-Estimators

Minimize a robust loss function:

$$\sum_{i=1}^n \rho\left(\frac{x_i-\mu}{\alpha}\right)$$

Better for outlier-contaminated data
